Late train or on time?

You are the station announcer. A model gives every train a late-risk score, and you decide when to sound the alarm. Drag the threshold bar below and watch every metric, chart and count react.

The data and the model

Download train_journeys.csv and keep it beside your Python file. The code cells that follow are meant to be run in order; setup steps are at the bottom of the page.

Cell 1: Load the data
# %% Cell 1: Load the data
import pandas as pd, numpy as np, matplotlib.pyplot as plt

df = pd.read_csv("train_journeys.csv")      # keep the CSV next to this .py file
print(df.shape)
print(df.head())
print("Late rate:", round(df["late"].mean(), 3))
Cell 2: Split, scale and train
# %% Cell 2: Split, scale and train
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

X = df.drop(columns="late")
y = df["late"]
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, stratify=y, random_state=42)

scaler = StandardScaler().fit(X_tr)
model = LogisticRegression().fit(scaler.transform(X_tr), y_tr)
proba = model.predict_proba(scaler.transform(X_te))[:, 1]   # late-risk score, 0 to 1
print(proba[:5].round(3))

Confusion matrix: four possible outcomes

Every train ends up in exactly one box. Rows are what really happened, columns are what the announcer said. Each square below is one of the unseen test trains.

TP FN FP TN

Cell 3: Confusion matrix
# %% Cell 3: Confusion matrix at a threshold
from sklearn.metrics import confusion_matrix, ConfusionMatrixDisplay

THRESH = 0.5                                  # change me, then re-run cells 3 onward
pred = (proba >= THRESH).astype(int)
tn, fp, fn, tp = confusion_matrix(y_te, pred).ravel()
print(f"TP={tp}  FN={fn}  FP={fp}  TN={tn}")

ConfusionMatrixDisplay.from_predictions(y_te, pred, display_labels=["on time", "late"], cmap="Blues")
plt.title(f"Confusion matrix at threshold {THRESH}")
plt.show()

Accuracy and why it can fool you

Accuracy asks: out of all trains, how many did we get right, in either direction?

Cell 4: Accuracy and the lazy baseline
# %% Cell 4: Accuracy and the lazy baseline
from sklearn.metrics import accuracy_score

accuracy = (tp + tn) / (tp + tn + fp + fn)
lazy_accuracy = (y_te == 0).mean()            # a model that never warns anyone
print("Accuracy by hand:", round(accuracy, 3), "| sklearn:", round(accuracy_score(y_te, pred), 3))
print("Lazy model accuracy:", round(lazy_accuracy, 3), "(and it catches 0 late trains)")

Precision and recall: two different questions

Cell 5: Precision and recall
# %% Cell 5: Precision and recall
from sklearn.metrics import precision_score, recall_score

precision = tp / (tp + fp) if (tp + fp) else 1.0
recall = tp / (tp + fn)
print("Precision by hand:", round(precision, 3), "| sklearn:", round(precision_score(y_te, pred), 3))
print("Recall by hand:   ", round(recall, 3), "| sklearn:", round(recall_score(y_te, pred), 3))

F1 score: one number for both

Cell 6: F1 score
# %% Cell 6: F1 score
from sklearn.metrics import f1_score, classification_report

f1 = 2 * precision * recall / (precision + recall)
print("F1 by hand:", round(f1, 3), "| sklearn:", round(f1_score(y_te, pred), 3))
print("Plain average of precision and recall:", round((precision + recall) / 2, 3))
print(classification_report(y_te, pred, target_names=["on time", "late"]))

The threshold is a trade-off

● Precision ● Recall ● F1
● Late trains ● On-time trains: share of each group at each risk score

Right of the black line, the announcer warns. Raising the threshold removes false alarms (precision rises) but lets more late trains slip past (recall falls).

Cell 7: Sweep the threshold
# %% Cell 7: Sweep the threshold
ts = np.linspace(0.01, 0.99, 99)
prec_list, rec_list, f1_list = [], [], []
for t in ts:
    p = (proba >= t).astype(int)
    prec_list.append(precision_score(y_te, p, zero_division=1))
    rec_list.append(recall_score(y_te, p))
    f1_list.append(f1_score(y_te, p, zero_division=0))

plt.plot(ts, prec_list, label="Precision")
plt.plot(ts, rec_list, label="Recall")
plt.plot(ts, f1_list, label="F1")
plt.axvline(THRESH, color="black")
plt.xlabel("Threshold"); plt.ylabel("Score"); plt.legend()
plt.show()
print("Best F1 threshold:", round(ts[int(np.argmax(f1_list))], 2))

ROC curve and AUC: judging the model at every threshold

Each point on the ROC curve is the model at one threshold: how many late trains it catches (recall) against how many on-time trains it wrongly warns about (false alarm rate). The red dot is your current threshold.

AUC-ROC = area under the blue curve

0.5 is a coin flip (dashed diagonal), 1.0 is perfect. On the right is the precision-recall curve, which is more honest when late trains are rare: its dashed baseline is the late rate.

Cell 8: ROC curve and AUC
# %% Cell 8: ROC curve and AUC
from sklearn.metrics import roc_curve, roc_auc_score

fpr, tpr, _ = roc_curve(y_te, proba)
auc = roc_auc_score(y_te, proba)
plt.plot(fpr, tpr, label=f"Model (AUC = {auc:.2f})")
plt.plot([0, 1], [0, 1], "--", label="Coin flip")
plt.xlabel("False alarm rate"); plt.ylabel("Recall"); plt.legend()
plt.show()
Cell 9: Precision-recall curve
# %% Cell 9: Precision-recall curve
from sklearn.metrics import precision_recall_curve, average_precision_score

prec, rec, _ = precision_recall_curve(y_te, proba)
plt.plot(rec, prec)
plt.axhline(y_te.mean(), ls="--")             # dashed line = late rate
plt.xlabel("Recall"); plt.ylabel("Precision")
plt.show()
print("Average precision:", round(average_precision_score(y_te, proba), 3))
